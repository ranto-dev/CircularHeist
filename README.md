# CircularHeist

CircularHeist est un projet TypeScript basé sur un problème d’optimisation utilisant la programmation dynamique.

## 📌 Description

Un voleur souhaite maximiser le gain obtenu en cambriolant des maisons disposées en cercle.

### 🚀 Contraintes :

- Il ne peut pas cambrioler deux maisons adjacentes.
- Les maisons sont disposées en cercle (la première est voisine de la dernière).

L’objectif est de trouver le gain maximal possible.

## 🛠️ Technologies utilisées

- TypeScript
- Node.js
- Jest (tests)
- Programmation dynamique
